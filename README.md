# TradeBrowser

This repository contains the source code for a web app used to browse USDA ERS Vegetable Trade data. Currently this is just a 90 MB+ CSV file that contains trade volumes (thousands of pounds) and values (thousands of US dollars) between the US and other nations, including a "World" summary. The web app allows you to chart these sets of data using a variety of charting methods and aggregation options.

## Data
The data in this case is just a CSV file downloaded directly from the USDA ERS website and stored in src/veg-trade-data.csv. Nothing special.

## Origin Story
This tool originally started life as the hbm_browser tool in the Philement/Hydrogem project, where it is used to explore that project's build metrics. Very different data, but the same kind of data > chart mechanism. In that case, the data is JSON data generated by its build tool that, over time, gives a bit of a perspective on its development. Reconfiguring it for TradeBrowser was done primarily via the use of assorted AI models, much like how hbm_browser was originally created.
